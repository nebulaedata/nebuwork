## 执行边界

任务工具以非 root 身份运行。容器 PID 1 只负责受保护的租约心跳与超时退出；Worker 强制退出后，旧容器会在续租停止后退出，重接管也会清理同一 Docker 主机的旧 fence 容器。任意外部写入仍不承诺绝对只执行一次；未知结果必须核对。

首版上传上限 20 MiB，工作区单文件上限 32 MiB，工作区 512 MiB、2 CPU、2 GiB 内存、256 进程；这些限制写入 Manifest。完整生产能力、成本和延迟应使用真实模型测量。

最终待验证路径：登录统一账号 → 重新配置模型和三个业务引擎 → 发布专家/工作台 → 创建项目任务 → 并行专家与真实业务工具 → 共享成果 → 更换 Worker 后继续对话。此项必须使用真实连接执行，不能以当前脚本模型验收替代。
