# 新智能体引擎与任务界面

运行路径为 React → Java 业务接口 → NebuAgentCoreNew2。任务主界面已替换为 React 组件和结构化事件 reducer，不再拼接整块聊天 DOM。旧 Core、模板目录及执行协议代码已退出当前实现。

桌面默认任务栏 260px、成果栏 360px，中间自适应；两侧支持拖动和键盘调整。窄屏采用可关闭抽屉。会话按执行轮次组织，工具调用只占一张持续更新的卡片，连续同类操作折叠分组。右栏提供文件版本预览、结构化计划、独立专家详情以及实际 Manifest。

消息区支持 Markdown、表格、代码和 artifact://ID/version 引用。图片不会自动请求模型提供的任意外部 URL。HTML 使用不带 allow-same-origin 的 sandbox iframe。向上阅读时保持位置，显示“有新进展”；历史分页、断线、重复和迟到事件按会话 sequence 汇合，账号切换中止旧请求。

工作台、专家和项目配置提供统一运行资源编辑器。表单和高级 JSON 维护同一份规范数据；上传完整目录保持 Skill 脚本、参考资料和素材的相对路径。保存草稿与发布分开，下一轮才使用新版本。任务模型和指令覆盖使用显式配置。

开发执行 `npm run dev`，网关和账号路径保持原配置。验证执行 `npm run check`，包含类型检查、Vitest、生产构建和既有 Sites 包装检查。浏览器验收已覆盖桌面/窄屏布局、真实执行记录、文件预览、配置来源、继续对话及刷新；截图位于本地 `.qa/agent-desktop.png`。

配套文档：Java 模块 README-agent-engine.md；引擎 README.md、docs/architecture.md、contracts/v1。真实模型和独立知识/工作流/记忆连接由现有管理入口重新配置，测试模型不作为生产默认值。

2026-10-16 专家知识库运行接入修复：原实现只读取项目知识库 ID，未传入专家库，也未向模型提供名称与 ID 目录；知识工具回调固定按项目来源读取。现改为主任务收集项目与已授权、已发布专家的知识库，委派专家仅接收项目公共库及自身库。引擎 Manifest 增加不含密钥的 `knowledgeReferences`，模型可以据此列出并调用检索；Java 按项目/专家来源路由，并在调用时重新验证当前权限。前端管理引用不需要重复添加或改动。需先更新引擎 API/Worker，再更新 Java，新 Run 生效，历史快照保持原样。

专项验证：引擎契约/目录/委派测试 6 项通过，TypeScript 构建通过；Java `AgentIntegrationTest` 6 项和 `KnowledgeApiTest` 19 项通过。覆盖无项目直接引用时的专家库发现、搜索与文档路由、委派范围隔离、非项目专家排除、禁用/解绑后的旧快照拒绝、账号隔离和旧 Manifest 兼容。Java 使用隔离 H2 和远端知识服务测试替身；尚未重启当前开发服务或执行用户真实模型与知识库的页面验收。
