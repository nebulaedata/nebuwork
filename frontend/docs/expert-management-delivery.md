## 本地入口与维护

2026-10-09 SOP 自定义连线：节点右侧输出圆点可以拖到目标左侧输入圆点，也支持依次点击两个圆点。支持分支、选中连线后删除（按钮或 Delete/Backspace）、Esc 取消连接/选择；拖动节点会更新线条位置。删除节点时同时删除关联连线，新增节点不自动连线。保存失败恢复服务端缓存中的图，离开页面或切换账号后忽略晚到的反馈。

连线以 `wf.edges: [{ id, source, target }]` 保存到 Java 的 `nw_sop.definition_json`，无需数据库迁移。未保存过 edges 的旧 SOP 保留顺序连接，显式 `[]` 表示没有连线；旧客户端省略 edges 时保留已有连接并清理已删除节点的引用。后台拒绝自连、重复连接、无效引用及超过 1000 条连线，沿用版本冲突和权限检查。此处仍为编排配置，不新增执行引擎。需更新并重启 Java 后使用；本轮仅补充前后端回归用例，未运行测试、构建、服务或浏览器验收。
