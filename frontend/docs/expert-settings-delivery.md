# 专家基本信息编辑与 AI 补全

入口为「专家详情 → 设置 → 基本信息」，在原有删除区域上方编辑专家名称、专业方向、基础模型和能力简介。「创建专家」与「专家设置」的能力简介都增加 AI 补全。

AI 使用表单所选的当前账号已保存模型配置，根据名称、专业方向和现有简介生成正文。结果先填入输入框，可继续编辑、撤销并恢复原文；创建或保存后才写入专家配置。生成期间如果人工修改了字段，AI 结果展示为建议，需要点击「应用补全」。失败保留原文；关闭创建弹窗、离开页面或切换账号后取消浏览器请求并忽略迟到结果。

模型下拉按配置 ID 选择，不能通过同名模型借用其他账号的凭据。如果现有模型配置不在当前账号列表中，可以保留现有绑定并修改名称、方向和简介；AI 补全须先选择自己的配置。当前补全支持 OpenAI 兼容配置，即现有 mrtoken/custom 和历史 openai 类型。调用不创建任务，也不计为专家任务执行。

## 后端接口及数据

- `POST /api/agents/{expert}`：`revision`、`name`、`role`、`tagline`，可选 `modelProviderId`。校验统一身份、专家可见状态、模型归属和专家修订号，保存后返回更新的 profile。冲突返回 409；页面保留输入。沿用已有共享专家元数据模型，账号移除状态及历史发布快照保留。
- `POST /api/agents/ability-completion`：`name`、`role`、`tagline`、`modelProviderId`。返回 `tagline` 与所用配置 ID，不写入专家记录。禁止提交服务地址、API Key 或用户身份覆盖项。
- 浏览器路径仍经 `/nebulaedev/nwaa/api/...`。Java 读取当前账号的配置、解密密钥并调用配置的 `/chat/completions`，使用现有来源策略与内网白名单、固定 DNS 结果、TLS 主机校验、禁止重定向及自动重试。错误不包含上游正文或密钥。
- `nebu.models.completion-timeout-ms` 可在 Nacos 配置，默认 60000，范围 1000～120000 毫秒。并发最多 8 个请求，响应最多 1 MiB，简介最多 2000 个字符。浏览器取消后上游请求最迟在服务端期限结束。

沿用 `nw_expert` 的现有字段、修订号及审计表，本次不增加迁移，Core 不变。需要更新 Java 服务和前端。
