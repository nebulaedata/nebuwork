# 功能梳理

## 1. 工作台与全局能力

- 登录页、会话守卫、浅色/深色主题。
- 六类垂直工作台及项目、运行任务、Token 用量汇总。
- 专业工作台配置：维护业务本体定义，并引用共享知识库、专家智能体与案例模板。
- 全局任务/消息搜索、通知中心、用户菜单、用量与帮助入口。
- 指挥官视图：对话式创建项目、节点关系、执行概览。
- 情报视图：订阅源、地图信号、项目情报关联。

## 2. 项目中心

- 项目列表：工作台筛选、状态筛选、搜索、新建项目。
- 项目概览：项目状态与基础资料编辑、会话任务、成员专家、用量。
- 项目资产：记忆、文件树与预览、知识库、数据库连接、定时任务、扩展和情报。
- 后端支持项目列表、聚合详情、新建与受控字段更新。

## 3. 专家智能体

- 专家列表、新建专家、专家详情与跨项目任务记录。
- 模型、角色、SOP、知识库、插件、等级、经验与成功率展示。
- SOP 集支持工作流编排和标准化流程两种形态；工作流节点可拖拽、编辑、添加和删除。
- 业务规则库支持规则场景集、自然语言规则、启停、筛选、新增、编辑与删除。
- Agent Core 按专家 SOP 生成执行计划，以插件名形成工具轨迹，通过 Provider 接口生成结论。
- 同时提供普通 JSON 执行和 SSE 事件流，轨迹回写会话审计。

## 4. 任务会话

- 项目会话切换、普通/定时任务筛选、多专家执行选择。
- 消息发送、停止、复制、删除、回滚、重试、评价。
- 右侧待办面板实时展示 Agent 的任务计划、执行中、阻塞和完成状态；Run 执行期间由 Agent 自动维护，任务完成后用户可点击待办人工标记完成或重新打开。
- 后端持久化进程内消息、Agent 回复、SOP 工具事件与审计记录。

## 5. 广场与治理

- 案例模板复用、共享知识库、市场专家雇佣。
- 扩展市场：Skill、MCP、Plugin 能力展示。
- 管理设置：成员、连接器、执行器、扩展授权申请、审批与拒绝原因。

## 6. 当前实现边界

- 初始 mock 数据完全不变；运行期新建/编辑数据仅存在内存。
- Agent 默认使用确定性模型 Provider，便于离线演示和自动测试；Provider 接口可替换为真实大模型。
- 登录为原型会话守卫，尚未接企业 SSO/RBAC。
- 文件、数据库、连接器和定时任务当前完成产品交互与数据契约，尚未接真实外部基础设施。
