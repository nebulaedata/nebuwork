## 使用入口

知识库详情及专家、工作台、项目的授权引用共用 `#/knowledge` 二级页面，顶部提供“检索、原文、Wiki、图谱、图片”。浏览和原文阅读在页面内展开；原有编辑、历史和维护操作保留在有权限账号的“内容管理”入口。

- 搜索命中直接按分块读取上下文，保留引用文本、来源位置和文件指纹。文档列表仍可分页阅读全文。
- Wiki 提供目录、搜索、正文内链接、正反向链接、页面关系图及来源文档。实体图谱单独显示，保留文档实例身份、边方向、数量上限及截断提示；节点可展开邻域并核验来源。
- 图片提供分页、关键词、来源文档、多种动态属性筛选、排序、大图、描述和 OCR。筛选与排序字段来自上游配置；图片通过 Java 资源接口读取。后端操作名仍为 gallery。
- 原文阅读器提供原文件、解析正文和下载。PDF、DOCX、PPTX、表格、Markdown、文本、图片、音视频、EPUB 和 HTML 按需加载渲染器；PPTX 在局部 Vue 组件中渲染。HTML 使用不授予脚本和同源权限的沙箱，并禁止外部资源。
- 定位结果区分精确、结构、部分、缺失、重复及版本失配。旧 DOC/PPT、未支持格式或缺少映射时，保留真实可用的正文和下载，不宣称完成定位。历史资料不会自动重新解析。

## 接口及工具

Java 现有 `/read` 的 `search/document/documents` 保持兼容，补充 `capabilities/chunk/graph/gallery/wiki.folders/wiki.graph/wiki.stats`；`contentKind` 区分 document/faq/wiki。能力分别返回 supported、enabled、available；未执行运行探测时 available 为 unknown，实际查询失败明确报错。旧 MCP 驱动只声明原有能力。

新增目录连接和对象引用的 POST `preview/media`。请求只接受库、文档、分块、图片等资源标识，拒绝地址和未知字段。Java 校验当前账号、连接、引用和资源归属，再获取二进制；凭据、签名地址和存储地址不会进入浏览器或模型结果。

WeKnora 新增 POST `/api/v1/knowledge-bases/:id/graph/query`，以及 GET `/api/v1/knowledge-bases/:id/images/:chunk_id/:image_index/content`。复用原 retrieve/API Key、Viewer、KBAccessRead 和文件授权。图谱数据库查询、返回节点/边及来源均受限，来源再次验证所属库及当前文档。

New2 保留 `knowledge_search/knowledge_document`，增加 `knowledge_capabilities/knowledge_documents/knowledge_wiki_search/knowledge_wiki_page/knowledge_graph/knowledge_gallery`。Java 固定工具调用的引用和内容类型，并禁止模型读取停用分块；提示词要求区分原文、Wiki、关系和图片描述，使用真实 evidenceUrl。

## 证据与权限

V21 `nw_knowledge_evidence` 持久化任务、轮次、调用、授权引用、引用快照及稳定证据 ID。证据和调用完成回执在同一事务提交，失败回滚；同一调用重放复用完成结果及 ID。

任务 Markdown 的 `evidence://ke_…`、工具卡及专家结果均可打开阅读器。GET `/api/tasks/{task}/evidence/{id}` 返回快照，POST `/read` 分页读取绑定来源，POST `/preview`、`/media` 获取绑定资源。证据接口不允许替换任意文档或图片；Wiki 导航通过已授权的普通引用接口读取。每次操作重新检查任务归属、当前项目/专家授权和连接；本轮调用还检查冻结授权。历史任务没有证据 ID 时保留原结果。

导航、切换账号和关闭阅读器会中止请求；迟到响应不会更新界面。渲染器和 Blob 资源随阅读器清理；缩略图队列限制并发。二级页保留原引用的授权路径和安全返回地址；旧设置详情书签跳转到新路由。
