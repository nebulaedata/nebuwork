# 任务执行联通（V9）

本批由工作台智能体执行。创建任务不调用模型，发送目标才产生 Run。任务使用项目固定的工作台版本，每个 Thread 有独立工作目录；同项目默认并行 2 个，全局 4 个。

业务、归属、模型凭据和知识授权由 Java 管理；核心负责 Thread、Run、工具执行及不可变成果。浏览器仅访问 `/nebulaedev/nwaa/api`。不接入多专家编排、定时触发、任意 MCP、自动归档或专家记忆回流。

实施及验收说明见 Java 模块 `README-task-execution.md`。用户自行运行迁移、服务、测试及构建，本次开发不代运行。

## 任务文件上传

任务详情的“任务文件”标题栏提供“上传文件”，对话收起时也可直接使用。支持多选，附件不能为空，单文件最大 20 MiB；历史演示任务、非活动项目和未准备完成的任务不可上传。上传期间展示文件序号，完成后立即更新文件列表并加入下一条消息附件；上传本身不启动执行。

复用已有 Java 接口 `POST /nebulaedev/nwaa/api/projects/{projectId}/files`，使用 `multipart/form-data`，字段为 `file`、`taskId`，并携带 `Idempotency-Key`。同一账号、项目、任务下的同名同内容文件复用请求编号，网络失败后可重新选择原文件重试。后端验证账号与任务归属并将文件保存到 Core，任务详情接口负责恢复已上传文件；无需新增接口或数据库迁移。

验收时检查：对话收起后多选上传、上传完成后刷新仍可预览/下载、空文件及超限提示、上传失败后重试，以及上传过程中切换任务或账号不会把文件/错误提示写入新任务。发送目标时等待当前批次上传结束；文件会随下一条消息进入任务工作目录。

## HTML 浏览器预览

点击任务文件中的 `.html` / `.htm`（扩展名不区分大小写）会进入“浏览器预览”；顶部浏览器入口也会列出本任务上传、生成及引用的 HTML 文件和网页访问记录。页面使用可用面板高度，支持查看源码、重新加载、下载和返回文件列表。更新文件列表和刷新任务时保留未变化的 HTML 文档，避免重置图表等交互状态。

正文复用 Java 的产物预览接口，按需读取完整文件，不使用浏览记录中的摘要。HTML 在 `sandbox="allow-scripts"`、`referrerpolicy="no-referrer"` 的 iframe 中渲染，不授予 `allow-same-origin`、弹窗或顶层导航权限。单文件内的脚本、样式可运行；外链资源仍依赖网络和资源自身的访问策略，相对路径的配套资源不属于本次单文件预览。沿用后端 2 MiB 在线预览限制，超限展示下载提示。

补充 `htmlPreview.test.js` 回归用例，覆盖文件/顶部入口、HTML 隔离、源码转义、下载、刷新保留页面、失败重试和切换任务时忽略旧响应；测试、构建与浏览器验收仍由使用方执行。
