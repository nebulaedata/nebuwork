# NebulaeKno v0.1.0 实施与验收

日期：2026-10-23。对应设计基线：v1.6。该版本完成基础设施启动契约、React 后台与核心知识处理/检索链路。完整设计中的高级能力仍有待接入项，详见本文最后一节。

## 交付物

| 位置 | 内容 |
| --- | --- |
| `cmd/nebulaekno`、`internal` | 独立 Go API、启动器、迁移、任务工作器、模型协议、检索与来源服务 |
| `reader` | 本地 Python 解析/OCR/Office/媒体处理子进程 |
| `web` | React、TypeScript、Vite、TDesign React 后台；PDF.js、Video.js、React Flow |
| `Dockerfile` | 前端与 Go 多阶段构建，运行时包含解析器、中文字体、FFmpeg；非 root 用户 |
| `compose.yaml` | 仅一个正式应用服务，8080 端口、`/data` 命名卷 |
| `.env.example` | 三个必填连接 URL，以及有默认值的运行预算 |
| `/api/docs`、`/api/openapi.json` | 与服务路由同步注册的接口目录与 OpenAPI |
| `tests/compose.yaml` | 独立测试中间件；固定测试项目名、隔离网络和卷 |

本地镜像标签：`nebulaekno:0.1.0`。仅绑定本机的验收应用地址：`http://127.0.0.1:18080`。正式部署默认端口 8080。没有使用或初始化正式数据库连接。

当前 OpenAPI 归档包含 102 个路径、120 个操作，见 [openapi.json](openapi.json)。浏览器中从检索结果打开视频来源后，已读取播放器实际 `currentTime=0.2`，与引用的 200 毫秒位置一致。

## 默认配置

- PostgreSQL 17 + pgvector 0.8.x、Neo4j Community 5.26 LTS + 匹配 APOC Core、Redis 7.4/db0/AOF/noeviction；不提供数据库类型切换。
- 文件目录、Wiki、图谱默认开启；简体中文；图谱实体覆盖人物/组织/地点/产品/项目/技术/概念/事件/流程。
- 文本分块 512 字符、重叠 80；默认混合检索 top_k=10、candidate_k=50、RRF k=60、向量/关键词权重 0.7/0.3。
- 文档/图片/媒体工作器 2/2/1；模型调用全局并发 4，可配置单模型超时与并发。
- 视频每 30 秒一帧、最多 240 帧，超出帧预算时扩大间隔并记录；媒体默认最长 4 小时。
- 字号正文 14px，标题 22/17/14px，绿色主题。表单、表格、上传、弹窗、树直接使用 TDesign React。

## 验收方法与边界

自动化验收使用 `nebulaekno-test` 或 `nebulaekno-config-test` 隔离环境。正式部署只需填写自己的三个连接 URL，然后应用才会初始化对应数据库。

| 验证 | 覆盖内容 |
| --- | --- |
| `go test -race ./...`、`go vet ./...` | 配置与身份、事务迁移、并发初始化、权限、迁移校验和/指纹冲突、事务中断恢复、字符偏移、API 就绪门禁、字幕时间校验 |
| `tests/startup.py` | 错误 URL/密码/网络/APOC/Redis 策略阻止启动；启动与重启；依赖中断撤销就绪并恢复；关键子进程崩溃使容器退出 |
| `tests/functional.py` | 8 类真实样本 DOCX/MD/MP4/PDF/PNG/PPTX/WAV/XLSX；上传幂等、解析分块、Unicode 原文核验、八模式检索、范围隔离、图片查询、ASR 时间、分片冲突、重排 |
| `tests/versions.py` | 视觉/ASR/多模态输入测试；目录与预览独立重建；重解析旧引用；字幕偏移；图谱证据；Wiki 修订回滚；凭证清除；Range；OpenAPI |
| `tests/contracts.py` | 全局默认值与知识库快照；关闭 Wiki/预览；未就绪能力错误；待配置文件保存；禁止旧任务覆盖新解析版本 |
| `tests/recovery.py` | 处理中停止容器并清空隔离 Redis，恢复后不重复解析；事件续接；取消/重试；知识库与来源删除 |
| 前端生产构建与实际浏览器 | TypeScript/Vite 构建；知识库与状态；窄屏表格；目录与原文高亮；PDF 离线渲染；图谱证据跳转；媒体播放与时间定位 |

功能测试使用明确命名的内部模型协议测试桩，通过真实 HTTP 请求验证接口协议与数据链路。测试桩不装入正式部署，也不代表实际模型的语义召回、图谱抽取、视觉或 ASR 质量。接入实际模型后仍须使用业务样本评测质量。

## 当前限制与后续项

以下能力不会作为已完成能力返回模拟成功：

1. 图片透视/倾斜矫正、逐字 OCR 框及坐标逆变换尚未接入；预处理接口返回 `CAPABILITY_NOT_READY`。本地 Tesseract 为整页/整图定位；PaddleOCR-VL 可提供版面区域定位与 PDF 高亮，缺少合法坐标时回退为页级定位。Office 转换副本不宣称原生段落与 PDF 坐标精确对齐。
2. PDF/Office 内嵌图片的独立资产提取、SVG/GIF 等仅预览资产模式待补充。当前图片入库主要覆盖独立图片、扫描页识别与视频帧。XLSX 默认提供解析表格；需要版式 PDF 可发起独立预览重建。
3. 音视频暂未接入逐词时间对齐、说话人分离、VAD、音轨选择及指定时间窗口的阶段级重跑；重处理当前只支持完整流水线。ASR 服务必须返回可校验的分段时间；不会由纯文本伪造时间。
4. 分块人工编辑/停用与修订管理、检索对比页、解析器临时预览、后台协调备份尚未接入。处理配置 AI 建议已支持图片要求和图谱配置生成、预览及选择填入。文件夹 API 已实现，文档文件夹与标签编辑界面仍需扩展。
5. 目录辅助模型只接受能在原文中核验的标题；不保证任意无结构文件都能产生完整目录。Wiki/图谱做引用与范围核验，事实质量仍取决于模型及资料；重建旧引用不改写历史文件。
6. 向量维度不超过 2000 时建立 HNSW 索引，更高维度使用精确计算。当前中文关键词使用字符/双字符 token 和 PostgreSQL 全文检索，不宣称 BM25。不同向量空间通过排名融合，不混加原始相似度。
7. 尚未做生产规模并发、长媒体及真实模型成本/质量基准。大规模上线前应按实际数据量测量处理时长、内存、索引规模和召回指标。

完整备份必须配套保留 PostgreSQL、Neo4j、文件卷和 `/data/config/installation.json`；Redis 队列可以从 PostgreSQL 恢复。安装密钥与数据库错配时应用拒绝启动。
