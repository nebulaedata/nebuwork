# Docker 本地开发

本服务已迁入 NebuWork 的 knowledge/V101。统一开发环境见仓库根目录 deploy/dev/README.md 和本目录上一级的 NEBUWORK.md。

在 NebuWork 根目录执行 scripts/Start-Dev.ps1，访问 http://localhost:18080，从“设置 → 知识库”进入 V101。知识库 API、参数提取、PostgreSQL 和 Neo4j 只在 Docker 专用网络中提供服务。

本目录不包含智能体核心，不需要初始化或启动原仓库的智能体 API、Worker、沙箱或 MinIO。NebuWork 现有智能体保持独立。

单独部署仍可使用本目录 Dockerfile、Dockerfile.extraction、compose.yaml 和 .env.example。独立接口沿用原无登录设计，应置于受控网络；NebuWork 集成由 Java 网关提供账号、归属和权限。
